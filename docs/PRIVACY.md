# Privacy policy — OMJAPAN

OMJAPAN stores learning progress and user preferences locally on the device. There is no account, advertising SDK, analytics upload or crash reporting.

## Data stored on the device

- Profile and onboarding choices
- Settings such as theme, accent, daily goal, JLPT target, romaji, furigana, audio and notification preference
- Kana, vocabulary, kanji and lesson progress
- Bookmarks and saved items
- Quiz history, scores and wrong answers
- Opportunity tracker status, private notes and checklist state
- Cached official feed items, if a verified feed is ever enabled

## Network use

- Core learning content is bundled in the APK and works offline.
- The user can tap Refresh in Opportunity Radar to request official feeds. No usable official feed was confirmed at release, so no unverified endpoint is enabled.
- Creator avatars, if displayed, load from YouTube only while online; a monogram is used offline.
- External links open outside the app. The app does not embed or track video playback.

## Permissions

- `INTERNET`: official refresh and external links.
- `ACCESS_NETWORK_STATE`: honest offline/online state in the radar.
- `POST_NOTIFICATIONS`: only used if the user enables deadline reminders.

## User control

Settings provides JSON backup/export, content-cache clearing and full erasure of local progress, bookmarks, notes and history. Uninstalling the app also removes local data.
